# La Mesita de Candy

Sitio web oficial de **La Mesita de Candy**. Comida casera los sábados a partir de las 11:30 AM.

## ¿Qué es este proyecto?

Una página web de una sola vista (Landing Page) para mostrar el menú, la ubicación y los datos de contacto del negocio. Incluye un carrusel de fotos automático y un menú dinámico que se carga desde un archivo JSON.

## 🛠️ Tecnologías

- HTML5
- CSS3 (Diseño responsive)
- JavaScript (Vanilla)
- GitHub Pages (Hosting)
